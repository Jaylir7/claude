# 功率半導體與 AI 基礎設施

> [!info] 重點一句話
> **電越猛 ≠ MOSFET 越多,而是「MOSFET 越搶」。** 一個原本平淡的成熟零件,因為 AI 供電瓶頸 + 8 吋產能被排擠,變成搶貨賽道。

## 一、功率半導體(MOSFET)為什麼變搶貨賽道?

### 1. 起點:AI 一代比一代吃電
- 單顆 GPU 功耗:B200 **1000W** → GB200 **2700W**
- 單一機櫃功率(3 年約 25 倍):Hopper 40kW → Blackwell 120kW → Kyber '27 **1MW**
- 卡關的不是算力,而是 **「怎麼把電送進晶片」**
- 電壓低(12V / 54V)→ 電流就得拉大 → 銅排 I²R 損耗暴增、發熱嚴重
- 一座 1MW 機櫃,光 54V 銅排就吃掉 **≈ 200 公斤銅**
- ➡️ 不是銅比較差,是銅撐不住 → **只能把電壓往上拉**

### 2. 解法:把電壓一路往上拉(12V → 48V → 800V)
> [!note] MOSFET 是什麼
> 電源電路裡的「精密開關」,靠**閘極(Gate)電壓**控制電流通斷,負責升降壓、交直流轉換、過壓保護。屬於**主動元件(電力的調度者)**。結構:源極 Source / 閘極 Gate(+V)/ 汲極 Drain,閘極加電壓 → 通道 Channel 導通 → 電流通過。

| 升級階梯 | 效益 | 狀態 |
|---|---|---|
| 12V → 48V | 電壓×4、電流÷4 → 損耗降約 **16 倍**,單台 MOSFET ×2~3 | 主流升級中 |
| 54V → 800V | 銅省 ~45%;英飛凌 54V 已遇容量瓶頸 | NVIDIA「Kyber」2027 起 |

➡️ **每往上一階,就要塞進「更多顆」MOSFET**

### 3. 為什麼電越猛,MOSFET 反而越缺?
1. **數量↑**:48V 要更多級降壓,單台伺服器 MOSFET ×2~3
2. **單顆面積↑**:電壓拉到 800V / 1200V,高壓裸晶尺寸放大

> [!important] 核心結論
> 電越猛 ≠ MOSFET 越多;**電越猛 = MOSFET 越搶**

### 4. 製造卡在最老的 8 吋晶圓
- 物理事實:**耐壓越高,一片切得越少**(600V ≈ 上千顆/片 → 1200V ≈ 數百顆/片)
- 供給在縮 + 磁吸效應:
  - 台積電、三星削減成熟製程(2027 部分廠全停)
  - 全球 8 吋 2026 估 **−2.4%**、利用率衝 **90%+**、代工調漲 **5~20%**
  - 產能優先給高利潤 AI PMIC → **排擠其他功率元件,連車規一起被擠**
- ➡️ 功率元件從「平淡零件」**變成供需結構的根本翻轉**

### 5. 技術兩條演化路
- **路線一|矽基「換結構」(這波主力):** 平面 Planar → 溝槽 Trench → 超接面 SJ,**導通電阻一路壓低**
- **路線二|直接「換材料」(第三代半導體):**
  - **SiC 碳化矽** — 高壓高功率(EV 800V、電網)
  - **GaN 氮化鎵** — 高頻(二次側 DC-DC)
  - **Si 矽** — 成本敏感的主力
- 為什麼難?① 吃 8 吋產能 ② 認證週期長(車規/雲端,以年計)③ 材料門檻高(SiC 生長慢、晶圓薄又脆)
- ➡️ **不是 SiC/GaN 取代矽,是三者「各守生態位」、共存分工**

## 二、CPO 共封裝光學(光互連)

> 主題從「電怎麼進晶片」延伸到「資料怎麼用光送出去」。

**封裝垂直堆疊(上→下):** GPU/Switch(旁有 HBM)→ Interposer 中介層 → MCM → PCB
**互連層級(細→粗):** Hybrid bonding pad → µbump → Bump / BGA Ball

**光引擎三件套:**
- **EIC**(電子晶片)— 驅動與訊號處理
- **PIC**(光子晶片)— 電 ↔ 光轉換核心
- **FAU**(光纖陣列)— 光的進出口
- **C2C** — 晶片間電互連介面

**收發鏈路:** C2C → OE(光電轉換)→ 光纖 → OE → C2C,共 9 條 lane;不同顏色=不同波長(**WDM 分波多工**,一根光纖跑多色光 → 頻寬倍增)

> [!tip] 意義
> 把光引擎搬到 GPU 旁一起封裝,用光取代板上銅走線 → 更低功耗、更高頻寬、更短延遲。與第一部分「銅撐不住」是同一物理困境的兩面。
